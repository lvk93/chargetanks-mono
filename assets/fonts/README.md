# Schriften

- `latinmodern-math-subset.woff2`: Latin Modern Math (GUST e-foundry), lizenziert unter der GUST Font License
  (https://www.gust.org.pl/projects/e-foundry/licenses). Teilmenge (Latein, Griechisch, Operatoren, kursive
  Mathe-Buchstaben) aus `latinmodern-math.otf`, erzeugt mit `pyftsubset --layout-features='*' --flavor=woff2`.
  Wird nur in den Mathe-Boxen des Kapitels verwendet; ohne MATH-Tabelle setzt Chrome Indizes zu tief.
